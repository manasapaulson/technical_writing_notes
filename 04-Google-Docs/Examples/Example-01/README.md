# Google Docs Practical – Example 01

## Overview
This practical demonstrates the use of Google Docs for creating, editing and formatting documents.

## Features Demonstrated
- Text formatting (bold, italic and underline)
- Headings and styles
- Bulleted and numbered lists
- Tables
- Headers and page numbers
- Version history
- Document sharing
