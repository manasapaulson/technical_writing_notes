# Technical Writing Notes

A collection of notes, examples, and practical references prepared as part of the Technical Writing course.

## Topics Covered

### 1. LaTeX

Notes covering the fundamentals of LaTeX, mathematical typesetting, document formatting, and visual elements.

| No. | Topic | Description |
|---|---|---|
| 01 | Introduction to LaTeX | Overview of LaTeX, its features, document structure, compilation, and basic commands. |
| 02 | Mathematical Notations | Mathematical expressions, equations, Greek symbols, fractions, arrays, matrices, and lists. |
| 03 | Math Constructs | Mathematical fonts, symbols, equation environments, alignment, and advanced mathematical formatting. |
| 04 | LaTeX Tables | Creating and formatting tables, merging cells, captions, references, spacing, and colours. |
| 05 | Colours and Figures | Adding colours, inserting images, resizing, rotating, cropping, and arranging figures. |
| 06 | Picture Environment | Drawing basic diagrams using coordinates, lines, vectors, circles, boxes, and other picture commands. |

### 2. Beamer
Notes on creating presentations and slides using LaTeX Beamer.

### 3. Doxygen
Notes on documenting source code and generating documentation using Doxygen.

### 4. Google Docs
Notes on document creation, formatting, and collaboration using Google Docs.

### 5. Git
Notes on version control and essential Git commands.

### 6. GitHub
Notes on repositories, commits, branches, remote collaboration, and project management.
